Create a modern, mobile-first social media style web app UI called “SkillSnap”.

Design style:
Clean, minimal, high-trust, similar to Instagram + TikTok UI. Use soft shadows, rounded corners, smooth spacing, and a neutral color palette with one strong accent color. Focus on simplicity and real-world usability.

Main goal:
A platform where skilled people showcase their real work through short videos and photos, and nearby users can discover, trust, and connect with them.

Do NOT build functionality. Only design static UI screens.

HOME FEED SCREEN (Main Screen)
Vertical scrolling feed of short video cards (TikTok style)
Each card includes:
• Video thumbnail
• Username + profile image
• Skill tag (e.g., Barber, Tiler, Makeup Artist)
• Location (e.g., “Liverpool, NSW”)
• Caption (short description)
Overlay actions on right side:
• Like icon
• Comment icon
• Share icon
PRIMARY ACTION:
• Add a clear “Connect” button on each card
• Positioned prominently but not intrusive (bottom or overlay)
• Represents instant connection after viewing content
Bottom navigation bar:
• Home
• Discover (Map icon)
• Upload (+ button center)
• Messages
• Profile
DISCOVER (MAP VIEW)
Map-style screen showing nearby skilled professionals
Pins/icons represent different skills
Top search bar: “Search skills or location”
Filter chips:
• All
• Nearby
• Top rated
• Categories (Barber, Cleaning, Fitness, etc.)
Bottom draggable card preview showing selected profile
PROFILE SCREEN (SKILLED USER)
Profile header:
• Profile image
• Name
• Location
• Short bio
Action buttons:
• Message
• Follow
Section: “My Work”
• Grid of video/photo thumbnails
Clean, professional, portfolio-style layout
Do NOT include reviews or completed work section at this stage
UPLOAD / SHOWCASE SCREEN
Simple UI for uploading content
Buttons:
• Upload Video
• Upload Photo
• Import from social media
Caption input field
Skill category selector
Location auto-fill display
Primary button: “Post”
MESSAGES SCREEN
Chat list layout:
• Profile image
• Name
• Last message preview
• Timestamp
Clean WhatsApp-style UI
CHAT SCREEN
Conversation layout:
• Message bubbles (left/right)
• Input field at bottom
Conditional action button:
• “Send Job Completion Request”
• This button should appear as disabled by default
• Indicate it becomes active after meaningful interaction (e.g., after conversation and time delay)
Keep UI minimal and clear
CLIENT PROFILE (Viewer Type)
Same structure as skilled profile
Focus on saved posts and interactions instead of uploads
AUTH / ONBOARDING SCREEN
Welcome screen:
• Title: “Watch. Trust. Connect.”
• Subtitle: “Discover real skills near you”
Buttons:
• Sign up
• Log in
No role selection (users can both view and post)

General UI Rules:

Mobile-first responsive design
Consistent spacing and typography
Use icons for clarity
Prioritize video-first experience
Keep UI intuitive and familiar
No complex animations needed

Output:
Generate all screens as a cohesive UI system with consistent styling.
