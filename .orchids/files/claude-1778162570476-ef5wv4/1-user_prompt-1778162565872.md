Three layout fixes on SkillSnap (skillsnap.com.au) — apply to both landing page and logged-in feed:

━━━━━━━━━━━━━━━━━━━━━━━
1. NAV CARD — more breathing room
━━━━━━━━━━━━━━━━━━━━━━━
The middle nav icons card is too tight. Fix:
  - Padding inside card: 14px top/bottom, 10px left/right
  - Gap between icons: increase from current to 12px
  - Keep all other styles (border, border-radius, active state, Post purple circle) unchanged

━━━━━━━━━━━━━━━━━━━━━━━
2. CENTRE the content block (feed + right sidebar)
━━━━━━━━━━━━━━━━━━━━━━━
Currently the feed and right sidebar sit too far left with dead space on the right. Fix so it mirrors Threads proportions:

  - Wrap the feed column + right sidebar in a single container with:
      max-width: 820px
      margin: 0 auto
      padding-left: 80px
    The padding-left: 80px offsets for the fixed left sidebar so the content appears truly centred in the remaining viewport space — NOT just centred in the full viewport width. This is critical.

  - Target column widths:
      Feed column: max-width 480px (fixed, does not stretch on wide screens)
      Right sidebar: ~300px
      Gap between feed and right sidebar: 24px

  - On a 1440px screen the result should look like:
      ~80px left sidebar | balanced margin | 480px feed | 24px | 300px right sidebar | balanced margin
      Equal whitespace on left and right of the content block

━━━━━━━━━━━━━━━━━━━━━━━
3. RIGHT SIDEBAR — change to sticky positioning
━━━━━━━━━━━━━━━━━━━━━━━
Change the right sidebar from position: fixed to:
    position: sticky
    top: 16px
    align-self: flex-start
This keeps it visible as the user scrolls the feed without overlapping any content — the same behaviour as Threads and Twitter. Do NOT use position: fixed on the right sidebar.

━━━━━━━━━━━━━━━━━━━━━━━
4. FEED COLUMN — fixed width, no stretching
━━━━━━━━━━━━━━━━━━━━━━━
Add max-width: 480px to the feed column itself so it never stretches on large screens. The feed should always be a consistent narrow column regardless of viewport width, matching the Threads/TikTok style.

━━━━━━━━━━━━━━━━━━━━━━━
5. RESPONSIVE — hide right sidebar below 1200px
━━━━━━━━━━━━━━━━━━━━━━━
At viewport widths below 1200px (common on 1280px laptops), hide the right sidebar entirely so the feed column has enough room and does not get squeezed:
    @media (max-width: 1200px) { right sidebar: display none }
The feed column should remain centred when the right sidebar is hidden. Test that the layout looks clean at both 1280px and 1440px screen widths.

Do not change colours, fonts, left sidebar styles, or any other functionality.
