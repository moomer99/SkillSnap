Implement guest browsing on SkillSnap (skillsnap.com.au) — applies to both desktop and mobile:

━━━━━━━━━━━━━━━━━━━━━━━
1. "BROWSE AS GUEST" ENTRY POINT
━━━━━━━━━━━━━━━━━━━━━━━
Add a "Browse as guest" option in two places:

DESKTOP — landing page:
  - Add a subtle text link below the "Join Free" button
  - Text: "Just browsing? Continue as guest →"
  - Style: small font (13px), muted colour (grey), no underline, hover shows underline
  - Clicking it takes the user directly to the feed as a guest

MOBILE — login/signup screen:
  - Add a text link below the Log In button
  - Text: "Continue as guest →"
  - Same subtle style as above
  - Tapping it takes the user directly to the feed as a guest

━━━━━━━━━━━━━━━━━━━━━━━
2. GUEST SESSION — what they can see
━━━━━━━━━━━━━━━━━━━━━━━
When browsing as guest, the user sees the EXACT same UI as a logged-in user:
  - Full feed with videos
  - Left sidebar (SK logo + merged nav card) — visible to guests
  - Right sidebar — visible to guests
  - Discover/map page — fully accessible to guests, no sign-up required
  - Can scroll the feed and watch videos freely

━━━━━━━━━━━━━━━━━━━━━━━
3. ACTIONS THAT TRIGGER SIGN-UP POPUP
━━━━━━━━━━━━━━━━━━━━━━━
When a guest attempts any of the following actions, immediately show the sign-up popup (do NOT perform the action):
  - ❤️ Like a post
  - 📩 Connect button
  - 🔖 Save a post
  - ➕ Post (create content)
  - 👤 View any user profile
  - Tapping Messages in nav
  - Tapping Profile in nav

Discover and Feed remain freely accessible without triggering the popup.

━━━━━━━━━━━━━━━━━━━━━━━
4. SIGN-UP POPUP DESIGN
━━━━━━━━━━━━━━━━━━━━━━━
The popup should appear as a bottom sheet on mobile and a centred modal on desktop:

Content:
  - SkillSnap logo at top (small, centred)
  - Headline: "Join to unlock the full experience"
  - Subtext: "Like, connect and post your work — free forever"
  - "Sign Up Free" button — full width, solid purple (#6C63FF), white text
  - "Log In" button — full width, outline style, purple text
  - Small "✕" dismiss button top-right corner so user can go back to browsing

Mobile style:
  - Slides up from the bottom
  - border-radius: 20px 20px 0 0 on top corners
  - background: white
  - padding: 24px 20px
  - Has a small drag handle bar at the very top (grey pill, 40px wide, 4px tall, centred)
  - Semi-transparent dark overlay behind it

Desktop style:
  - Centred modal
  - border-radius: 16px
  - max-width: 380px
  - background: white
  - padding: 32px
  - Semi-transparent dark overlay behind it
  - Closes on clicking outside or pressing Escape

━━━━━━━━━━━━━━━━━━━━━━━
5. LEFT SIDEBAR — hide on landing page only
━━━━━━━━━━━━━━━━━━━━━━━
The left sidebar (SK logo card + merged nav card) should:
  - Be HIDDEN on the marketing/landing page (the page with "Don't read reviews. Watch the work.")
  - Be VISIBLE once the user enters the app — whether logged in OR browsing as guest
  - The SK logo card at top-left can remain visible on the landing page as the brand mark

━━━━━━━━━━━━━━━━━━━━━━━
6. RIGHT SIDEBAR — fix to viewport (stop scrolling away)
━━━━━━━━━━━━━━━━━━━━━━━
Change the right sidebar from position: sticky back to position: fixed so it stays visible at all times while the feed scrolls. Set a top value that aligns it with the top of the feed content area (e.g. top: 70px to clear the header). Make sure it does not overlap the header.

Do not change colours, fonts, feed width, or any other functionality.
