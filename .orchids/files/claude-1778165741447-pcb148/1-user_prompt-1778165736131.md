Fix three issues on SkillSnap (skillsnap.com.au):

1. FIX GUEST SESSION BUG
━━━━━━━━━━━━━━━━━━━━━━━
Currently clicking "Browse as guest" opens the user's existing logged-in account instead of a true guest session. This happens even in incognito windows — meaning the guest flow is broken at the auth level.

Fix this by implementing guest mode as a simple client-side flag, completely separate from Supabase auth:

- When user taps "Browse as guest", do NOT call any Supabase auth method
- Do NOT check for or use any existing Supabase session
- Instead, set a localStorage flag: localStorage.setItem('skillsnap_guest', 'true')
- Immediately redirect the user to the feed page
- On every page load, check for this flag alongside the Supabase session:
    - If Supabase session exists → logged in user
    - If localStorage flag 'skillsnap_guest' === 'true' → guest user
    - If neither → unauthenticated, show landing page
- When a guest signs up or logs in → clear the guest flag: localStorage.removeItem('skillsnap_guest')
- Guest mode persists until they log in, sign up, or manually log out

━━━━━━━━━━━━━━━━━━━━━━━
