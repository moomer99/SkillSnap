Fix the 2-second white screen when opening a chat in ChatScreen.tsx.

PROBLEM: When useChat has no cached messages, it sets loading=true which 
causes ChatScreen to render a blank white screen for ~2 seconds while 
Supabase fetches messages.

FIX — in useChat.ts:
Change the loading initial state from false to true:
  const [loading, setLoading] = useState(true);

This means the skeleton loader shows immediately on mount instead of a 
white flash before loading kicks in.

Also in useChat.ts, in the fetchMessages() function, add a minimum 
skeleton display of 0ms (no artificial delay) — just make sure setLoading(false) 
is only called AFTER messages are dispatched, not before. 
Currently the order is correct — no change needed there.

FIX — in ChatScreen.tsx:
The loading skeleton currently only renders inside the messages container.
The white screen happens because the outer div renders with a white/light 
background before the skeleton appears.

Find the loading skeleton block:
  {loading ? (
    <div className="flex flex-col gap-3 mt-2">
      {[false, true, false, true, false].map((isMe, i) => (
        ...skeleton divs...
      ))}
    </div>
  ) : ...}

Replace the skeleton content with a more visible one that fills the screen:
  {loading ? (
    <div className="flex flex-col gap-3 mt-2 px-2">
      {[false, true, false, true, false, false, true].map((isMe, i) => (
        <div key={i} className={`flex ${isMe ? "justify-end" : "justify-start"}`}>
          <div
            className={`h-9 rounded-2xl animate-pulse ${isMe ? "bg-[#d4c9ff]" : "bg-[#ede9de]"}`}
            style={{ width: `${38 + (i * 17) % 40}%` }}
          />
        </div>
      ))}
    </div>
  ) : ...}

Do not change any other logic. Only fix the white screen flash on chat open.
