Fix deleted conversations and deleted messages not persisting after 
refresh in messageService.ts.

PROBLEM 1 — Conversations:
getThreads() uses get_my_threads RPC which doesn't return the hidden 
column from conversation_members. The filter !m.hidden always evaluates 
to false because hidden is undefined.

FIX: After the RPC call, do a separate query to get the hidden status 
for the current user's memberships:

Replace this block:
  const visibleMemberships = (memberships as Record<string, unknown>[])
    .filter((m) => !m.hidden);

With this:
  const { data: hiddenRows } = await sb
    .from("conversation_members")
    .select("conversation_id")
    .eq("user_id", userId)
    .eq("hidden", true);

  const hiddenSet = new Set(
    (hiddenRows ?? []).map((r: Record<string, unknown>) => 
      r.conversation_id as string)
  );

  const visibleMemberships = (memberships as Record<string, unknown>[])
    .filter((m) => !hiddenSet.has(m.conversation_id as string));

PROBLEM 2 — Messages:
getMessages() uses this filter:
  .or(`sender_id.neq.${userId},deleted_for_sender.eq.false`)

This is incorrect PostgREST syntax. It should use:
  .filter("deleted_for_sender", "eq", false) 
   combined with sender check

Replace the messages query with:
  const { data, error } = await getAuthSupabase()
    .from("messages")
    .select("*")
    .eq("conversation_id", conversationId)
    .order("created_at", { ascending: true });

  // Filter out messages deleted by sender on client side after fetch
  const filtered = (data ?? []).filter((row: Record<string, unknown>) => {
    if (row.sender_id === userId && row.deleted_for_sender === true) {
      return false;
    }
    return true;
  });

  return filtered.map((row) => 
    mapMessage(row as Record<string, unknown>, userId));

No other changes.
