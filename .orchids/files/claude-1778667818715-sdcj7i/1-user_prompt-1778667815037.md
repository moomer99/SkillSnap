Fix the realtime subscription error in useChat.ts:
"cannot add postgres_changes callbacks after subscribe()"

PROBLEM: The subscribeToMessages call in messageService.ts is 
being called multiple times for the same conversation because 
React strict mode or re-renders cause the useEffect to fire 
twice, and the perConvChannels registry cleanup is async 
(uses await removeChannel) which doesn't complete before the 
next subscribe attempt.

FIX — in useChat.ts, add a subscribing guard ref to prevent 
double-subscription:

1. Add a new ref:
   const isSubscribingRef = useRef(false);

2. Wrap the subscription block with the guard:
   if (subscribedConvRef.current !== threadId) {
     unsubRef.current?.();
     unsubRef.current = null;
     subscribedConvRef.current = threadId;

     if (!isSubscribingRef.current) {
       isSubscribingRef.current = true;
       unsubRef.current = messageService.subscribeToMessages(threadId, (msg) => {
         dispatch({ 
           type: "APPEND_THREAD_MESSAGE_IF_NEW", 
           threadId, 
           message: msg 
         });
       });
       isSubscribingRef.current = false;
     }
   }

3. Also reset the guard on cleanup — add to the return cleanup function:
   return () => {
     document.removeEventListener("visibilitychange", handleVisibility);
     clearInterval(pollInterval);
     isSubscribingRef.current = false;
     // Do NOT unsubscribe here — subscription persists for same conversation
   };

No other changes.
