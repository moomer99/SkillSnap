Fix scroll issues across multiple screens. The root cause is that 
flex children are not properly constrained inside height:100dvh containers.

CHANGE 1 — ChatScreen.tsx
The outer wrapper already has overflow-hidden and height:100dvh. 
The messages container already has flex-1 min-h-0 overflow-y-auto.

The problem: jobCardRef div, messagesAfterCard div, scroll button, 
Mark Job as Done div, QuickReplies, and input bar are all direct 
children of the outer flex column but have no flex-shrink-0.

Wrap all content BELOW the messages container (from jobCardRef div 
down to and including the input bar div) in a single wrapper:
  <div className="flex-shrink-0 flex flex-col">
    {/* jobCardRef div */}
    {/* messagesAfterCard div */}
    {/* scroll to bottom button */}
    {/* Mark Job as Done div */}
    {/* QuickReplies */}
    {/* input bar div */}
  </div>

This tells the flex column: messages take all remaining space, 
everything below is fixed height and never grows.

CHANGE 2 — UploadScreen.tsx
The outer wrapper uses min-h-screen which causes the page to grow.
Change:
  <div className="flex flex-col min-h-screen bg-[#f8f7f5]">
To:
  <div className="flex flex-col bg-[#f8f7f5] overflow-hidden" 
    style={{ height: "100dvh" }}>

The inner scrollable div:
  <div className="flex-1 overflow-y-auto no-scrollbar px-4 pt-5 pb-28 ...">
Change to:
  <div className="flex-1 min-h-0 overflow-y-auto no-scrollbar px-4 pt-5 pb-10 ...">
