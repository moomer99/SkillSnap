Improve Video Card UX & Consistency

The video card is much cleaner after removing the Follow button and Top Rated badge. Now I'd like to polish the experience and make every card consistent.

1. Always show the Connect button (High Priority)

The Connect button must always appear on every public video card.

Fix the bug where some cards do not display the Connect button.
The only exception should be when a user is viewing their own profile/card (if intentionally designed that way).
Every visitor should always have a clear primary action.
2. Reduce the Connect button height

The current Connect button is visually too dominant.

Please:

Reduce its height by approximately 15–20%.
Keep it full width.
Keep the same colors, border radius, icon, and animation.
The button should remain the primary CTA while allowing the video content to stand out more.
3. Always display the user's role

Every video card should always show a role beneath the user's name.

Examples:

Driver-On-Call
Driver
Wizz55
Barber

If no role has been provided, display:

—

instead of leaving the space empty.

This keeps every card visually aligned and avoids inconsistent layouts.

4. Limit description height

Some descriptions become too long and push the statistics section downward.

Please:

Display a maximum of 2 lines.
Truncate anything longer.
Show "See more" only if the description exceeds two lines.
Maintain consistent spacing between cards regardless of description length.
5. Improve the statistics row

Keep the current layout, but make it slightly easier to read.

Please:

Increase the stat icons by about 10%.
Slightly increase the spacing between each stat column.
Keep the same order:
Jobs Done
Connections
Happy
Distance
Goal

Every video card should have the exact same visual structure:

Video
User name
Role (always visible)
Description (maximum 2 lines)
Statistics
Connect button (always visible)

The objective is to create a cleaner, more premium, and consistent experience while keeping the video as the main focus and making Connect the single clear call-to-action.
